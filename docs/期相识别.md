# `pj_medkit.phase` --- CT 期相识别

**源代码：** [pj_medkit/phase.py](../pj_medkit/phase.py)

---

本模块判断一次 CT 检查里各序列是平扫、动脉期、静脉期还是延迟期。只读 DICOM 文件头，不读图像，所以很快，也不需要分割结果。

最常见的用法是给一个检查目录：

```python
>>> from pj_medkit.phase import classify_dir
>>> result = classify_dir("/data/study_001")
>>> result["rule_version"]
1
>>> for s in result["series"]:
...     print(s["series_number"], s["description"], s["phase"])
2 Abdomen 5.0 0
3 Abdomen A 5.0 1
4 Abdomen P 5.0 2
```

模块提供四个函数，按"省事"到"灵活"排列：

|函数|适用情况|
|:---|:---|
|[`classify_dir()`](#classify_dir)|手里有一个检查目录，让模块自己找文件|
|[`read_series_header()`](#read_series_header)|已经知道每个序列该读哪个文件|
|[`classify_phases()`](#classify_phases)|已经有各序列的文件头字段值，只要判断|
|[`guess_phases()`](#guess_phases)|判断不了的序列也必须有一个期相，按扫描先后补|

> **备注：** 判断结果和"一共有哪几个序列参与"有关，比如增强序列按采集先后排，前两个是动脉期、静脉期。参与判断的序列要先筛好：定位像、重建序列、同一期的薄层和厚层混在一起时，结果会受影响。

## 函数

<a id="classify_dir"></a>

### `classify_dir(dicom_dir, liver_hu=None, series_uids=None, fallback=False)`

判断一个检查目录里各 CT 序列的期相，返回一个字典。

*dicom_dir* 是检查目录的路径，字符串或 `Path` 均可，子目录里的文件也会扫。只处理 `Modality` 为 `CT` 的文件；不是 DICOM 的文件、SEG 等其他类型的文件自动跳过。每个序列取中间一层的文件头。

*liver_hu* 是各序列的肝脏平均 CT 值，格式为 `{SeriesInstanceUID: 数值}`，没有就不传。它只在少数情况下起作用，见[肝脏平均 CT 值](#肝脏平均-ct-值)。

*series_uids* 是 SeriesInstanceUID 的列表。给出时只有这些序列参与判断；不给则目录里所有 CT 序列都参与。

*fallback* 决定判断不了的序列怎么办。默认 `False`，`phase` 为 `None`；为 `True` 时按[兜底规则](#兜底规则)补一个期相，并把该序列的 `guessed` 标为 `True`。

返回值的结构：

|字段名|类型|说明|
|:----|:---|:-----|
|rule_version|int|规则版本，即 [`PHASE_RULE_VERSION`](#PHASE_RULE_VERSION)|
|series|list[dict]|参与判断的序列，按序列号从小到大排|
|series[].series_uid|str|SeriesInstanceUID|
|series[].series_number|int \| None|序列号|
|series[].description|str \| None|序列描述|
|series[].phase|int \| None|[期相编码](#期相编码)；判断不了且没开 *fallback* 时为 `None`|
|series[].guessed|bool|期相是否是兜底补的。`False` 表示按规则判出来的，或没判出来；没开 *fallback* 时恒为 `False`|

```python
>>> classify_dir("/data/study_001")
{'rule_version': 1,
 'series': [{'series_uid': '1.2.840.113619.2.1', 'series_number': 2,
             'description': 'Abdomen 5.0', 'phase': 0, 'guessed': False},
            {'series_uid': '1.2.840.113619.2.2', 'series_number': 3,
             'description': 'Abdomen A 5.0', 'phase': 1, 'guessed': False},
            {'series_uid': '1.2.840.113619.2.3', 'series_number': 4,
             'description': 'Abdomen P 5.0', 'phase': 2, 'guessed': False}]}
```

某个序列判断不了时，只有它的 `phase` 为 `None`，其他序列照常给出。是否因此整体不采用，由调用方决定。目录里没有 CT 序列时 `series` 为空列表。

开了 *fallback* 后每个序列都有期相。补的期相没有依据，给医生看或存档前建议用 `guessed` 区分开。

采集时间相同的序列按序列号排先后。兜底时有序列缺采集时间的，整例按序列号排先后。

*在 1.0.0.0 版本加入。*

<a id="read_series_header"></a>

### `read_series_header(path)`

读一个 DICOM 文件的文件头，返回 [`classify_phases()`](#classify_phases) 需要的字段：`{desc, protocol, contrast, acq, bolus}`。补上 `key` 就能直接传入。

*path* 是文件路径。一个序列读一层即可，建议取中间一层。

```python
>>> read_series_header("/data/study_001/s3/12.dcm")
{'desc': 'Abdomen A 5.0', 'protocol': 'Liver', 'contrast': True,
 'acq': 63903024330.0, 'bolus': 63903024300.0}
```

文件读不了时抛出 pydicom 的异常（不是 DICOM 文件时为 `pydicom.errors.InvalidDicomError`），由调用方处理。

各字段取自这些文件头标签：

|返回字段|文件头标签|说明|
|:---|:---|:---|
|desc|SeriesDescription|序列描述|
|protocol|ProtocolName|协议名|
|contrast|ContrastBolusAgent|是否用了造影剂；标签为空或值为 `NONE`、`NO`、`N`、`0`、`无` 时为 `False`|
|acq|AcquisitionDate（没有时用 SeriesDate）、AcquisitionTime|采集时间，秒。不用 SeriesTime：它常是重建时间，会打乱先后|
|bolus|ContrastBolusStartTime|注药开始时间，秒，与 `acq` 同一起点；注药在零点前、采集在零点后的情况已处理|

*在 1.0.0.0 版本加入。*

<a id="classify_phases"></a>

### `classify_phases(series, liver_hu=None)`

按[判断规则](#判断规则)判断各序列的期相，返回 `{key: 期相编码}`。判断不了的序列不出现在结果里。

这是模块的核心函数，不读任何文件，[`classify_dir()`](#classify_dir) 内部也是调它。

*series* 是参与判断的序列列表，每项是一个字典：

|字段名|类型|说明|
|:----|:---|:-----|
|key|str|调用方给序列起的标识，序列号或 SeriesInstanceUID 均可，返回结果用它作键|
|desc|str \| None|序列描述|
|protocol|str \| None|协议名|
|contrast|bool|是否用了造影剂|
|acq|float \| None|采集时间，秒|
|bolus|float \| None|注药开始时间，秒，与 `acq` 同一起点|

*liver_hu* 是各序列的肝脏平均 CT 值，格式为 `{key: 数值}`，没有就不传。

```python
>>> from pj_medkit.phase import classify_phases
>>> series = [
...     {"key": "2", "desc": None, "protocol": None,
...      "contrast": False, "acq": 28800, "bolus": None},
...     {"key": "3", "desc": None, "protocol": None,
...      "contrast": True, "acq": 29130, "bolus": 29100},
... ]
>>> classify_phases(series)
{'2': 0, '3': 1}
```

采集时间相同的序列按传入顺序排先后。

*在 1.0.0.0 版本加入。*

<a id="guess_phases"></a>

### `guess_phases(series, phases)`

给 [`classify_phases()`](#classify_phases) 判断不了的序列按[兜底规则](#兜底规则)补一个期相，返回 `{key: 期相编码}`。结果里只有补的序列，已经判出来的不在里面，也不会被改。

*series* 和传给 [`classify_phases()`](#classify_phases) 的是同一个列表，*phases* 是它的返回值。

```python
>>> from pj_medkit.phase import classify_phases, guess_phases
>>> series = [
...     {"key": "2", "desc": None, "protocol": None,
...      "contrast": False, "acq": 28800, "bolus": None},
...     {"key": "3", "desc": None, "protocol": None,
...      "contrast": True, "acq": 29130, "bolus": None},
...     {"key": "4", "desc": None, "protocol": None,
...      "contrast": True, "acq": 29160, "bolus": None},
... ]
>>> phases = classify_phases(series)
>>> phases
{'2': 0}
>>> guess_phases(series, phases)
{'3': 1, '4': 2}
```

两个结果合起来，每个序列都有期相。都判得出来时返回空字典。

补的期相没有依据，只用于必须每个序列都有期相才能继续的场合。

有序列缺采集时间时，整例按传入顺序排先后。

*在 1.0.0.0 版本加入。*

## 常量

<a id="期相编码"></a>

### 期相编码

|常量|值|期相|
|:---|:---|:---|
|`PHASE_PLAIN`|0|平扫|
|`PHASE_ARTERIAL`|1|动脉期|
|`PHASE_VENOUS`|2|静脉期|
|`PHASE_DELAY`|3|延迟期|

### `PHASE_NAMES`

期相编码到中文名的字典：`{0: "平扫", 1: "动脉期", 2: "静脉期", 3: "延迟期"}`。期相 2 统一叫"静脉期"。

<a id="PHASE_RULE_VERSION"></a>

### `PHASE_RULE_VERSION`

规则版本，当前为 `1`。判断规则、兜底规则或阈值有变化时加一。

把期相结果存下来的项目，建议连同规则版本一起存，以后能分清一条结果是哪版规则判的。

### 阈值

|常量|值|含义|
|:---|:---|:---|
|`ARTERIAL_MAX_SECONDS`|42|注药后不到这么多秒为动脉期|
|`VENOUS_MAX_SECONDS`|85|注药后不到这么多秒为静脉期，之后为延迟期|
|`ARTERIAL_MAX_RISE_HU`|15|肝脏比平扫高不到这么多 HU 为动脉期|
|`REPEAT_PLAIN_MAX_RISE_HU`|2|肝脏比最早的序列高不到这么多 HU，视为重复扫的平扫|

## 判断规则

规则分三步，前一步定不下来的才进下一步。

**第一步：分平扫和增强。**

- 有序列填了造影剂字段：没填的为平扫，填了的为增强。
- 整例都没填造影剂字段且只有一个序列：平扫。
- 整例都没填造影剂字段且有多个序列（医院可能不填这个字段）：
  - 有序列的描述里写明增强期的，带词的为增强，其余为平扫。认的词有 `A`、`AP`、`ART`、`Arterial`、`P`、`PV`、`Portal`、`V`、`Venous`、`D`、`DL`、`Delay`、`Delayed`、`C+`、`CE`，以及动脉、静脉、门脉、延迟、增强。英文按整词匹配，`B30f`、`D30f` 这类重建核名不算。
  - 都没写时，采集最早的为平扫。其余序列有注药时间的按增强；没有注药时间的看肝脏平均 CT 值，比最早的序列高 2 HU 及以上按增强，否则视为重复扫的平扫；两样都没有的判断不了。
  - 有序列缺采集时间时，整例都判断不了。

**第二步：增强序列按采集时间排先后。**

- 3 个及以上：依次为动脉期、静脉期，其余为延迟期。
- 1~2 个：
  - 有注药时间的按注药后秒数：小于 42 秒为动脉期，42~85 秒为静脉期，85 秒及以上为延迟期。
  - 第一个没有注药时间时，看肝脏比平扫高多少：不到 15 HU 为动脉期，否则为静脉期。
  - 第二个没有注药时间时顺延：动脉期之后为静脉期，静脉期之后为延迟期。

**第三步：看名称。** 以上都判断不了的增强序列（包括缺采集时间的），看序列描述和协议名里写明的期相：

|写了这些词|判为|
|:---|:---|
|`ART`、`Arterial`、动脉|动脉期|
|`PV`、`Portal`、`Venous`、静脉、门脉|静脉期|
|`Delay`、`Delayed`、延迟|延迟期|

同时写了多个期相的不采用。这一步不认单个字母，容易误判。

<a id="兜底规则"></a>

## 兜底规则

以上三步都判断不了的序列，默认不给期相。调用方要求每个序列都必须有期相时（[`classify_dir()`](#classify_dir) 的 *fallback*，或 [`guess_phases()`](#guess_phases)），按扫描先后补一个。补的期相是猜的，没有依据。

- **排先后**：序列都有采集时间时按采集时间；有序列缺采集时间时，整例按序列号（[`guess_phases()`](#guess_phases) 为传入顺序）。
- **分平扫和增强**：判断不了的序列按增强处理。整例都没填造影剂字段时例外：有序列的描述里写明增强期的，不带词的补为平扫；都没写时最早的补为平扫。
- **增强序列按先后补位**：已经判出来的保留。没判出来的接在前一个增强序列之后，依次为动脉期、静脉期、延迟期，前面没有增强序列的从动脉期起；同时不晚于它后面最近一个已判出来的期相。
- **只有一个增强序列且判断不了**：补为静脉期，单期增强扫的多是静脉期。

几个例子，`?` 是判断不了的增强序列：

|增强序列按先后|补完|
|:---|:---|
|`?`|静脉期|
|`?`、`?`|动脉期、静脉期|
|`?`、静脉期|动脉期、静脉期|
|动脉期、`?`、`?`|动脉期、静脉期、延迟期|
|`?`、动脉期、`?`|动脉期、动脉期、静脉期|

## 肝脏平均 CT 值

*liver_hu* 只在两种情况下用到：

- 整例都没填造影剂字段、序列描述也没写期相时，用它区分重复扫的平扫和增强。
- 只有 1~2 个增强序列且没有注药时间时，用它区分动脉期和静脉期。

它要先有肝脏分割结果才算得出来。在分割之前调用本模块时不传即可，这两种情况会退到看序列描述和协议名：写明了能判，没写就判断不了（开了兜底则按[兜底规则](#兜底规则)补）。分割完成后可以带上它再判一次。

## 日志

本模块用 loguru 输出日志。

- [`classify_dir()`](#classify_dir) 每次判断完输出一行 `期相识别完成`，带目录、各序列的结果，以及哪些序列的期相是兜底补的。
- 读文件头失败的文件输出 `期相识别读取文件头失败`，该文件跳过。一次扫描里只有第一个失败的带堆栈。

## 示例

**只让指定的序列参与判断**

目录里除了要分析的序列还有别的 CT 序列时，用 *series_uids* 指定：

```python
from pj_medkit.phase import classify_dir

result = classify_dir("/data/study_001",
                      series_uids=["1.2.840.113619.2.1",
                                   "1.2.840.113619.2.2",
                                   "1.2.840.113619.2.3"])
```

**有一个判断不了就整体不采用**

```python
from pj_medkit.phase import classify_dir

result = classify_dir("/data/study_001")
phases = {s["series_uid"]: s["phase"] for s in result["series"]}
if any(phase is None for phase in phases.values()):
    phases = {}
```

**判断不了的也要给一个期相**

每个序列都必须有期相才能继续时打开 *fallback*，用 `guessed` 分清哪些是补的：

```python
from pj_medkit.phase import classify_dir

result = classify_dir("/data/study_001", fallback=True)
phases = {s["series_uid"]: s["phase"] for s in result["series"]}
guessed = [s["series_uid"] for s in result["series"] if s["guessed"]]
```

**自己读文件头再判断**

已经知道每个序列中间一层是哪个文件时，不用扫整个目录：

```python
from pj_medkit.phase import classify_phases, read_series_header

middle_files = {
    "2": "/data/study_001/s2/40.dcm",
    "3": "/data/study_001/s3/40.dcm",
}
series = [{"key": key, **read_series_header(path)}
          for key, path in middle_files.items()]
phases = classify_phases(series)
```

**分割完成后带上肝脏平均 CT 值再判一次**

```python
from pj_medkit.phase import classify_dir

result = classify_dir("/data/study_001",
                      liver_hu={"1.2.840.113619.2.1": 55.2,
                                "1.2.840.113619.2.2": 61.0})
```

**显示期相名称**

```python
from pj_medkit.phase import PHASE_NAMES

name = PHASE_NAMES.get(phase, "未知")
```
